# Hey, I'm Muhammed Hashir 👋

Self-taught builder. I learn by breaking, fixing, and rebuilding systems in the real world.

Most of what I build sits at the intersection of **software and hardware** — repair systems, automation tools, and practical infrastructure that actually gets used.

> Build things that still work when everything else breaks.

---

### ⚙️ What I Work On

- **Backend systems** — mainly Go & PHP
- **Automation** — bots, workflows, infra
- **Repair-tech tools** — battery systems, diagnostics, service workflows
- **Desktop apps** — .NET WPF for business operations
- **Lightweight dashboards & utilities**

### 🚀 Projects

| Project | Stack | Description |
|---------|-------|-------------|
| **Revolt** | PHP / Laravel | Full ERP system for battery repair shops — job tracking, invoicing, warranty claims, billing, customer management |
| **Revolt Connect** | Go | WhatsApp WebSocket bridge — real-time messaging relay, bulk/scheduled sends, Windows service with auto-reconnect |
| **WhatsBridge** | Go / Docker | Cloud-deployable WhatsApp bridge — REST API, WebSocket relay, Koyeb-ready with MySQL + PostgreSQL |
| **LedgerX** | React / Node.js / Electron | Offline-first double-entry accounting software — journal entries, financial reports, backup/restore, runs on Windows |
| **GDP** | Laravel + .NET WPF | Group Purchase Distribution platform — shop owners place orders, backend merges into bulk POs, desktop app handles sort/pack/barcode dispatch |
| **PUC Center** | PHP / Laravel | Vehicle PUC testing center manager — expiry-based call queues, WhatsApp reminders, multi-tenant support |
| **Shoper** | .NET WPF / C# | Supermarket billing & inventory manager — barcode scanning, POS, GST compliance, thermal printing, stock tracking |
| **School ERP** | PHP / Laravel | School management system — admissions, attendance, grading, report cards, role-based dashboards |
| **TunnelPanel** | Go / Gin | Server control panel with Cloudflare Tunnel integration — manage sites, Docker containers, databases, all auto-tunneled |
| **Cloud Transfer Bot** | Go | Telegram bot that downloads files and uploads to Google Drive — dashboard UI, auto-cleanup, configurable via web |
